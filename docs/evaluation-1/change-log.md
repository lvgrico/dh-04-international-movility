# Evaluation 1 documents — change log (revision 1.1)

Why this file exists: while designing the architecture (Evaluation 2), the team found errors in the Evaluation 1 documents and decided new rules that contradict some of them. Revision 1.1 applies those changes so that all documents tell one story. Line-by-line detail is in the **Change Log** sheet of each workbook.

## 1. Corrections (errors in the original)

| Document | Correction |
|---|---|
| Vision | Objectives still used reservation-system wording ("organizers", "reservation history", "space usage"); rewritten for applicants, application history and utilisation of places |
| Requirements — Product Backlog | Four *Must* stories were missing: US-003, US-014, US-018, US-025 (added as *Proposed*) |
| Requirements — Risk Register | R-007 cited ASM-006 (adviser assignment); it now cites the new ASM-011 (equivalency workflow) |
| Requirements — Traceability | STK-07 had no row; a row now shows the gap explicitly |

## 2. Changes decided in Evaluation 2 (reversing earlier content)

| Item | Before | Now |
|---|---|---|
| CL-006 and ASM-004 | Submitted applications keep the requirements in force at submission; case by case | A **material** partner change, confirmed by the coordinator, **returns all active applications** for reapplication in a new period; students are told what changed, that they must redo the process and the new deadline; priority for previously approved students. CL-006 is *Closed – validate with client*; ASM-004 is *Superseded* |
| SC-10 and the STK-03 traceability row | A requirement change does not alter submitted applications | Reworded to match the rule above |
| CL-007 and US-011 | Destination change inside the same application | A destination change is a **new application** (several active applications are allowed) |
| US-025, US-026 | Nominated vs admitted; checklist for admitted students | Adds the student's **acceptance**; checklist for students who **accepted** |
| US-010, US-037 | Withdrawal; partner decisions in the simulated portal | Returns are recorded separately from withdrawals; the portal also carries partner change proposals and candidate selections |
